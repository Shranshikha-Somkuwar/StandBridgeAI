# StandBridge AI — SIH26108 Prototype

Responsive front-end prototype for SIH26108: AI-powered recommendation of applicable Indian Standards from procurement specifications.

Modules: Login, Dashboard, Requirement Analyzer, Standards Catalogue, History, Reports, Profile.

Important: this prototype uses illustrative standards records. It does not claim live BIS data or live amendment/certification verification. A production version should connect to authoritative standards data and validation workflows.

Run by opening `index.html` or using VS Code Live Server.
